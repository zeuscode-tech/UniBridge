# Draft user flows

## Flow A — newly arrived student
1. Select university and preferred language.
2. View an onboarding checklist.
3. Open one task (e.g., accommodation information).
4. Read sourced guidance and next action.
5. Optionally mark the task as reviewed.

## Flow B — find campus information
1. Open Information.
2. Select a topic (campus offices, transport, support, emergency contacts).
3. Read article, its source, and last-reviewed timestamp.
4. Follow the official source for confirmation.

## Flow C — ask a question (stretch)
1. Enter a question.
2. Search vetted resources first.
3. Show a source-linked response or explain that the answer is not available.
4. Direct the student to official channels for uncertain or consequential information.

## Proposed screens
1. Welcome / choose university
2. Home / priorities
3. Checklist
4. Information categories and article detail
5. Search / FAQ

All flows are drafts; design and user testing have not been completed.
