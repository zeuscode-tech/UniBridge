# Decisions and open questions

## Working assumptions (subject to validation)
- Name: UniBridge.
- Audience: international students arriving at a selected university.
- Geographic comparison: Kyrgyzstan and South Korea.
- Preferred format: mobile application with a research-backed initial prototype.
- Proposed stack: React Native / Expo; FastAPI and PostgreSQL only if needed.

## Questions to resolve
- Which two universities can be compared using accessible official materials?
- What first-week task is most difficult for incoming students?
- Which 3–5 content categories have the greatest measured value?
- Who can verify official content and how often must it be reviewed?
- Is a chatbot useful or would structured guidance be more reliable?
- Can a basic mobile app deliver value without account registration?
- What can realistically be completed before the interim and final presentations?
