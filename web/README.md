# UniBridge — web prototype

Вёрстка UniBridge по дизайн-манифесту v2.0 и макетам Figma-плагина. Рабочий прототип, а не статичные экраны: фильтры, план поступления, переключение направления и языка работают по-настоящему.

## Запуск

```bash
cd web
npm install
npm run dev       # http://localhost:5173
npm run build     # готовый сайт в dist/
```

`dist/` можно выложить на любой статический хостинг: роутинг через `#/`, серверные rewrites не нужны.

**GitHub Pages.** Workflow `.github/workflows/pages.yml` собирает сайт на каждый PR, а после merge в `main` публикует его. Один раз владельцу репозитория нужно включить Pages: *Settings → Pages → Source: GitHub Actions*. Адрес: `https://zeuscode-tech.github.io/UniBridge/`.

## Что исправлено относительно макетов

- **Вузы.** Вместо «University example A–D» — реальные вузы (13 в Корее, 9 в Кыргызстане; первыми идут Salymbekov University и партнёры), но только с проверяемыми фактами: название, город, тип, официальный сайт, год основания. Программы, языки, стоимость и сроки честно показаны как «Не указано / Не проверено» — по правилам манифеста (§20–21).
- **Фото.** AI-изображения кампусов больше не стоят на карточках реальных вузов (§30.2 это запрещает). У вузов — типографские обложки из их собственного названия (서울대, КНУ, АУЦА…), концепт-фото остались там, где они уместны: hero, направления, «О проекте» — с пометкой «Концепт-изображение».
- **Логотип.** Вместо буквы «U» в квадрате — знак-арка моста, как в брифе на логотип (§2.5).
- **Контакты.** Нет бэкенда — значит, нет фальшивого «Сообщение отправлено». Форма готовит issue в репозитории, отправка — на GitHub.
- **Фильтры.** Уровень, язык и стоимость не фильтруют по догадкам: блок объясняет, что они появятся после проверки данных.
- **Доступность.** Skip-link, фокус-кольца, ловушка фокуса в диалогах с возвратом фокуса, `aria-*` у табов и фильтров, `prefers-reduced-motion` отключает декоративное движение.

## Стек

Vite + React 18 + TypeScript, React Router, Lucide-иконки, шрифты Pretendard (интерфейс и хангыль, динамический сабсет), Inter (только кириллица) и Unbounded (крупные заголовки). CSS без фреймворка. Фирменный стиль «два флага, один мост»: токены и контраст каждой пары по WCAG AA — в `src/styles/tokens.css`, шкала шрифтов из 8 ступеней.

```
src/
  data/        вузы, стипендии, гайды, чек-лист — здесь же правится контент
  state/       язык и направление, план (localStorage)
  components/  шапка, подвал, карточки, диалоги
  pages/       страницы
  styles/      токены, база, компоненты, страницы
```

## Перед публикацией

Каждый вуз и стипендия имеют `status: 'needs_review'`. Когда команда сверит данные с официальным сайтом — поставьте `verified` и `lastVerified: 'YYYY-MM-DD'`, и бейдж сменится автоматически.
