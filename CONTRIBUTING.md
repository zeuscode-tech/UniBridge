# Contributing

This repository is an early-stage project. Please open an issue before starting a major feature so that work aligns with validated research findings.

## Workflow
1. Create a focused branch.
2. Explain the student problem and the evidence supporting your change.
3. Keep changes minimal and document assumptions.
4. Test user-facing flows, accessibility, and source links.
5. Submit a pull request with screenshots containing only fictional test data.

## Confidentiality
Never commit team rosters, phone numbers, emails, student IDs, private coordination documents, credentials, or identifiable interview material. See [privacy and publication policy](docs/PRIVACY_AND_SECURITY.md).

## Data and claims
Label unvalidated hypotheses as hypotheses; do not fabricate interview findings, test outcomes, integrations, analytics, or launch status.
