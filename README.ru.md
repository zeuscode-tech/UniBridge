# UniBridge — информация на русском

**UniBridge** — проект мобильного цифрового помощника для иностранных студентов в рамках международной программы HUSS Global Capstone Design.

**Текущий статус: планирование.** Готового приложения, завершённого исследования, подтверждённых интервью и работающего AI-ассистента пока нет.

## Проблема

При переезде в другую страну студентам бывает сложно быстро найти понятную и достоверную информацию о поступлении, заселении, жизни в университете, транспорте и экстренных контактах. Информация может быть разбросана по сайтам и документам на разных языках.

## Планируемый продукт

- Пошаговый список дел на первые недели.
- Справочник кампуса и важных сервисов.
- Поиск ответов по проверенной информации.
- Поддержка нескольких языков (по возможности).
- AI-помощник, отвечающий по подтверждённым источникам — дополнительная функция, не обязательная для первого MVP.

## План исследования

Сравнить информационные материалы для иностранных студентов **одного вуза Кыргызстана и одного вуза Южной Кореи** по общим критериям. По возможности провести несколько добровольных интервью и получить обратную связь на прототип.

## Цели по срокам

- **24 ноября 2026:** проблема, первоначальное исследование, UX-схема, интерактивный прототип, промежуточная презентация.
- **Декабрь 2026:** небольшая работающая версия приложения.
- **25–29 января 2027:** финальная презентация и выводы тестирования.

Сроки — **внутренние цели**, а не обещание завершённой разработки.

## Публичность и данные

В этом репозитории не следует размещать имена и контакты участников, телефонные номера, email, Student ID, списки команд, переписки, личные анкеты, ключи API и несогласованные интервью. Подробнее — [политика конфиденциальности репозитория](docs/PRIVACY_AND_SECURITY.md).
